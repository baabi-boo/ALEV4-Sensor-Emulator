# Phase 3 delegated development records

These files preserve the actual delegated task reports for the requested ten
waves of six agents. The machine-readable index records canonical task names,
completed report counts, archived byte sizes and SHA-256 digests. Reports retain
their original text. Where redundant terminal blank lines are removed, the
index records that transformation and the original size/hash; all other copies
are byte-identical. Reports are not rewritten as release evidence.

Early development reports identify the then-current ancestor HEAD together
with uncommitted-file hashes or explicit working-tree context. Those reports
are bounded execution/review notes. They do not claim that new uncommitted
Phase 3 code was present in that ancestor, or replace the later clean-source
acceptance record. Exact-source release execution is recorded separately in
`docs/evidence` and the Phase 3 completion report.

Commands and scratch paths in individual reports identify their original
execution context. Exploratory temporary files are not all retained in Git.
The committed production code, permanent regression suites and release command
are the maintained reproduction interface. Each report states its own scope;
source review, artificial verifier fixtures and runtime simulations remain
distinct kinds of evidence.

The final index and review log must contain exactly 60 completed unique tasks,
with six tasks in each of ten waves. Until then their status stays in progress.
