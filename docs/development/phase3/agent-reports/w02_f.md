## Implemented behavior

`[spatial,cfg,report] = alev4.isetSpatialFixture(kind,seed,exposure_s)` accepts
exactly uniform/ramp/checker/edge fixture names; seed defaults to 83 and
exposure to 0.001 s. It executes a real 32x32 ISET scene, 3-degree FOV, mean
padding, off-axis illumination skipped, genuine `oiCompute`, and genuine
`sensorCompute`. The returned sensor is checked as a centered 16x16 square
5-micrometre, full-fill-factor RGGB grid with imported generic effective QE.
Actual OI spacing must be at least the pixel pitch so native
`regridOI2ISA` uses its 1x1 Gaussian prefilter. Sensor output is analog volts
converted to fractional electrons, with autoexposure, read/shot noise,
quantization, vignetting and analog offsets disabled.

ISET optical-image values are explicitly point samples. `isetPointGrid`
constructs a bilinear reconstruction without extrapolation and requires every
native knot inside the requested extent to appear among cell edges. Four
corner values then give each exact cell average. The final partition includes
all native knots and all sensor boundaries, so the conservative cell sampler
integrates each footprint exactly up to floating-point roundoff. The spatial
wrapper receives `post_optics`, no additional PSF, and a complete geometry-bound
configuration. Its input cube, geometry, source cell edges, and operation order
are available for the new spatial artifact exporter.

An independent reference changes operation order: integrate spectral QE at
native points first, then use scalar bilinear evaluation and piecewise
rectangular footprint integrals. It does not call interp2, isetPointGrid,
cfaMap, or the overlap sampler. Separate source-cell refinement factors
[1,2,4,8,16] and native subpixel counts [1,3,9,27] record the approximation
errors against this reference. Checker/edge coarse controls must improve by
more than a factor of ten. Final exact-partition tolerance is 5e-12; fixed
native quadrature tolerance is 5e-5 with its single-precision limitation stated.
No strict monotonicity is required at every native refinement.

The report records actual optical support, point units, explicit reconstruction,
spectral mapping, CFA, image/pixel sizes, conversion convention, operation
order, native and reference electron arrays, convergence errors and observed
source/dependency provenance. Native point supports are recorded as sample
positions, not cell edges. A nonuniform fixture must produce nonuniform optical
planes, rather than merely differing Bayer colors.

Caller RNG, global vcSESSION presence/value, and the complete ISET preference
group are restored on success and post-setup error. Unsupported fixture names,
malformed parameters, missing dependencies, wrong coverage/spectral geometry,
extra native prefiltering, clipping, and failed numerical gates raise errors.
The conversion helper normalizes each plane while interpolating to avoid
artificial scale overflow/underflow, and rejects lost positive values.
