## Metadata boundary results

Both complete-bundle readers now agree on:

- **63-character key accepted; 64-character key rejected.** Non-ASCII, leading digit/underscore, punctuation, and control-character keys reject. Keyword spelling is case-sensitive, so `For` and `for_` remain valid.
- **256 object fields accepted; 257 rejected.** The controls use distinct portable keys in informational metadata.
- **64 total containers accepted; 65 rejected.** Separate controls terminate in a scalar, numeric vector, or numeric matrix, counting the outer manifest and all array levels.
- **Original numeric kinds preserved for validation.** Numeric fields supplied as one-element vectors/matrices reject, as do boolean dimensions, matrix-wrapped shape vectors, matrix-wrapped grid edges, wrapped descriptor byte counts, and nested metadata shapes other than `[]`.
- **Single-bin alternatives accepted.** Explicit one-element wavelength/bin-width vectors and a one-row RGB QE matrix pass in both single and dual mode. A three-row QE column rejects.
- **Malformed metadata arrays rejected.** Null, logical arrays, mixed arrays, ragged matrices, rank-three arrays, object/string arrays, and—after the fix—empty matrix rows reject.
- **String integrity preserved.** Literal/escaped NULs in keys and text, NUL-suffixed schema labels, and lone/malformed surrogate escapes reject. A paired surrogate and the literal text `\\u0000` pass.
- **Nested readout validation exercised.** Single/dual nested scalar wrappers, numeric authenticity labels, NUL runtime text, nonportable keys, image/CFA matrix wrappers, and malformed single descriptions reject. Nested mutations update the outer readout descriptor hash and byte count, so rejection reaches metadata checks rather than a checksum mismatch.
- **Numeric limitation bounded.** `0e0` accepts and nonzero `1e-9999` rejects. `0e9999` produces only the already documented native/Python difference.
