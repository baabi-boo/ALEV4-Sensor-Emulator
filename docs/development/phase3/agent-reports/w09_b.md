## Implementation

The helper keeps the original 44-file mapping and permits compression only for the 26 `.txt` paths that are actual stdout/stderr paths of the 16 expected commands. It compresses a qualifying text command log only when its original size is **strictly greater than 65,536 bytes**, appending `.gz` to the planned destination. JSON reports and receipts are never compressed by this policy.

Gzip uses compression level 9, `mtime=0`, an empty filename, and the platform-independent gzip OS marker. No timestamps or original filenames enter the gzip header. Deterministic bytes are scoped to the compressor implementation/runtime; independent recompression under this runtime matched every retained gzip file exactly.

Every catalog entry's existing `bytes` and `sha256` now describe the **stored file**. Every entry also records `storage_encoding` (`identity` or `gzip`), `original_bytes`, and `original_sha256`. Every compressed entry additionally records `decoded_byte_identical=true`. The latter is written only after reading the stored gzip back, decompressing it, comparing exact decoded bytes with the original, and comparing decoded length/SHA-256 with the original aggregate manifest. Original record kinds and execution/source associations are preserved.

Plain originals are written as unchanged bytes using exclusive file creation. Destination roots must be fresh; symlinks at destinations or ancestors reject. Each mapping is explicitly constrained to the proper fresh retention tree, and the catalog also requires a fresh, non-symlink path. All 44 source paths and retained paths must be unique. The helper checks full output-manifest equality before retention and again afterward, preserves the initially captured aggregate bytes, and retains the exact source/tree, release/development, both source-clean flags, 16-command, three-repeat, nested numerical-report, and raw nested-origin/copy equality checks reviewed in `w08_f.md`.

The helper imports `verify_phase3_artifacts.check_numerical_report` from the candidate repository. This validates report structure/prerequisites and provenance without rerunning numerical execution. The helper does not replace surrounding CI archive/download verification or whole-artifact verifier work.
