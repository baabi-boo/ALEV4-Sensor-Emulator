# Wave 1 assignment E — PSF, boundaries, and MTF design

## Scope

Read the repository's AGENTS.md, the full Phase 3 plan, and the existing sensor configuration's units/collection contract. This is a design review only: no production files changed, no implementation or numerical acceptance claimed. The geometry foundation must pass before implementation of this layer. All proposed optical kernels are explicitly synthetic; the inspected primary-source work does not provide a measured ALEV4 PSF.

## Recommended minimal interfaces

1. `psf = alev4.createOpticalPsf(overrides)` validates a separate versioned configuration.
2. `[filtered, filtered_grid, report] = alev4.applyOpticalPsf(irradiance, grid, psf)` applies the stated discrete convolution to spectral cell-average irradiance, returning a smaller fully supported grid and deterministic provenance.
3. `report = alev4.opticalMtf(psf, fx_cycles_per_m, fy_cycles_per_m)` evaluates the actual discrete kernel's complex transfer and magnitude at explicitly supplied physical spatial frequencies. An optional, separately labelled square-pixel aperture calculation may be returned; do not substitute it for the measured transfer of the full sampler.

Proposed PSF fields:

| Field | Contract |
| --- | --- |
| `schema_version` | Independent PSF schema, e.g. `1.0` |
| `kernel` | Dense real finite nonnegative H-by-W, or H-by-W-by-K, array |
| `origin_rc` | One-based integer `[row column]` inside kernel; the kernel sample representing zero displacement |
| `spacing_yx_m` | Positive finite `[row_spacing column_spacing]`, explicitly matching the input grid |
| `wavelength_nm` | Empty for one shared kernel; otherwise exactly one positive increasing wavelength per kernel plane and an exact match to the spectral input mapping |
| `boundary_policy` | Only `valid` / complete-support accepted initially |
| `parameter_sources` | Stable source-register IDs labelling kernels assumed/synthetic |

Use one kernel shared across bins or exactly K associated kernels. Reject a partial bank, implicit spectral interpolation, unknown fields, complex/negative weights, all-zero planes, nonfinite sums, invalid origins, and unsupported dimensions. Keep an explicit maximum kernel size so huge metadata cannot force unbounded convolution. Identity is `kernel=1, origin_rc=[1 1]` with matching sampling and shared wavelength policy.

For reproducible canonical metadata, the simplest strict contract is to require user kernels to be unit-sum within a documented floating-point tolerance, rather than normalizing arbitrary inputs silently on every revalidation. If a convenience constructor normalizes weights, record the original per-plane sum and normalize once; ensure repeated validation does not repeatedly perturb normalized coefficients or hashes. Each plane has its own unit-mass requirement. Sum tolerances should scale with kernel element count and machine precision; they are not radiometric accuracy claims. Reject normalization that overflows or erases originally nonzero contributions beyond the supported numeric range.

## Exact convolution and asymmetric origin convention

For input I with H rows and W columns and a kernel K of h rows and w columns, define

`J(i,j,k) = sum_a sum_b K(a,b,k) * I(i - (a-origin_r), j - (b-origin_c), k)`.

For a shared kernel the same K is used for every spectral plane. This is convolution, not cross-correlation. An impulse at `(ri,ci)` produces K at coordinates `(ri+a-origin_r, ci+b-origin_c)`. Do not assume symmetry when choosing convolution orientation.

All declared kernel positions must have valid input support. Consequently the retained physical input index ranges are:

- rows `h-origin_r+1 : H-origin_r+1`;
- columns `w-origin_c+1 : W-origin_c+1`.

The output array has `(H-h+1)` rows and `(W-w+1)` columns. `conv2(I(:,:,k), K(:,:,k), 'valid')` gives the correct numerical array, but its physical grid must use these origin-dependent coordinates. With grid edge vectors, crop y edges from `first_row` through `last_row+1`, and x edges analogously. The required incident halo is `[top bottom left right] = [h-origin_r, origin_r-1, w-origin_c, origin_c-1]`.

This works for odd, even, asymmetric, off-center, and singleton kernels. Example: K=`[1/4 3/4]`, origin column 1, and I=`[0 1 0 0]` yields the valid array `[1/4 3/4 0]` representing original columns 2:4. Origin column 2 yields the same array representing original columns 1:3. The grid offset is therefore essential even when the array bytes coincide.

Treat the entire declared kernel rectangle as support, including zero border coefficients. Do not infer a tighter crop from nonzero coefficients unless a later schema explicitly permits canonical trimming; otherwise shape and edge provenance become data-dependent. Reject kernels larger than the input in either axis. No zero padding, reflect padding, edge renormalization, wraparound, or implicit halo manufacture is permitted in this first contract.

## Uniform grid and units

The input grid may generally support nonuniform rectangular cells for resampling, but discrete shift-invariant PSF application requires uniform cell widths in each axis. Check every interval, not merely average extent divided by count. Compare intervals and PSF spacing with scale-aware relative/ULP tolerances; a one-metre absolute tolerance floor would be meaningless for micrometre grids. Reject unrepresentable differences, nonuniform axes, or mismatched PSF spacing before filtering. An identity kernel should still enforce the documented grid contract unless its no-op exception is explicitly documented and tested.

Output units remain photons/(m² s nm). The kernel is a dimensionless probability-mass stencil: no extra multiplication by spatial cell area belongs in convolution. No exposure, QE, Bayer mosaicing, fill factor, or pixel collection area belongs here either. Apply the PSF to spectral irradiance before sensor-area averaging and CFA response. Existing integration applies pixel area and fill factor once afterwards.

Identity should return the original dense input exactly, unchanged grid, and zero halo, avoiding arithmetic that needlessly changes values. For nonidentity convolution, normalized nonnegative weights preserve a flat field within roundoff on the retained region. They do not guarantee conservation inside an arbitrary output crop. To test impulse energy conservation, place the impulse far enough from every boundary that its entire output kernel remains within the retained region; otherwise report discarded boundary contribution rather than rescale it.

## MTF and phase oracle

At frequencies `(fx,fy)` in cycles/metre, use the actual discrete stencil:

`OTF(fx,fy,k) = sum_a sum_b K(a,b,k) * exp(-2*pi*1i*(fy*(a-origin_r)*dy + fx*(b-origin_c)*dx))`.

`MTF = abs(OTF)` for a unit-mass kernel. Return complex OTF (or real/imaginary parts for JSON), MTF, physical frequency vectors, Nyquist values `[1/(2*dy), 1/(2*dx)]`, origin, sampling, kernel dimensions, and a `synthetic/discrete_kernel` label. Require finite real frequency vectors and reject out-of-principal-band queries initially, rather than silently interpreting aliases. No FFT centering shortcut should erase origin phase. A pure shifted impulse has MTF 1 at every frequency and a nontrivial phase.

For the centered 1-D binomial stencil `[1/4 1/2 1/4]`, the real transfer is `0.5+0.5*cos(2*pi*f*spacing)`. A separable 2-D kernel has the product of the two axis responses. DC must be 1; the matching-axis Nyquist response is 0. Use the direct complex sum as an independent oracle for asymmetry, phase, and two-dimensional frequencies rather than comparing one FFT implementation against another.

Square photosite averaging of a continuous field has the separate aperture factor `sinc(fx*p)*sinc(fy*p)`, where sinc is `sin(pi*x)/(pi*x)` with sinc(0)=1. Label an optical-times-aperture curve as a stated continuous-field analytical model. The full discrete pipeline uses cell-average inputs and exact overlap sampling: an aligned equal-cell sampler is the identity on those discrete values, so appending another sinc to its measured discrete transfer would count averaging twice. End-to-end sinusoid tests must state whether the source array holds point samples or exact cell averages and compare against the corresponding oracle.

## Required independent tests

1. Identity: exact arrays, grid, expectations, seeded RAW and RNG state with both readout paths.
2. Asymmetric 1-D and 2-D impulses: verify kernel orientation, explicit origin, output coordinates, and translation covariance.
3. Even-size and off-center origins: verify all four halo counts and original-grid edge crops.
4. Flat fields at multiple spectral densities: test valid-region invariance and per-bin kernels without cross-wavelength mixing.
5. A direct scalar-loop convolution oracle independent of conv2; nonnegative linearity and intensity scaling.
6. Interior impulse energy sum with complete support; deliberately boundary-truncated impulse demonstrating loss without renormalization.
7. Binomial analytical OTF/MTF including DC and Nyquist; asymmetric direct-DFT phase; pure shifted impulse unit MTF.
8. Below-Nyquist sine and edge fixtures through blur plus overlap sampling with exact source-cell-average expectations; distinguish optical attenuation from pixel averaging.
9. Invalid nonuniform grids, spacing mismatch, kernel larger than input, unknown boundary policy, missing wavelength association, zero/negative/nonfinite kernels, fractional/out-of-bounds origins, and overflow.
10. Deterministic helpers leave the caller RNG untouched on both success and failure; user structs and source arrays remain unchanged.

## Provenance requirements

Record normalized coefficients and their hash, their spectral association, spacing and origin, normalization policy, `valid` boundary rule, exact retained index ranges/grid, input stage (`pre_psf` or already `post_optics`), and operation order. An ISETCam optical image is already post-optics; the spatial wrapper must not apply this standalone PSF to it implicitly. None of these mathematical checks establish equivalence to an ARRI lens, OLPF, microlens, or measured sensor aperture.
