## Static contract findings

`simulateSpatialExposure` validates options and geometry/readout binding, validates the spatial cube and plane count, applies explicit spectral optics when appropriate, conservatively samples density, and calls exactly one existing exposure API. Its `operation_order` follows that actual dispatch. `post_optics` rejects a nonempty PSF and carries an empty PSF result.

Both existing APIs call `integrateExposure`, which applies collection area, fill, exposure, spectral width and effective CFA/QE once. Spatial averaging and PSF helpers apply none of those collection or electronic factors. `applyDualGainNoise` samples once, clips the shared physical well once, then draws independent high/low electronic noise before readout and observable merge. Both existing readout helpers and the wrapper install cleanup-based RNG restoration.

The inspected existing `test_phase3_integration` contains 12 named groups. It was **read, not executed** here. The focused audit adds useful independent evidence beyond its cases: genuinely nonuniform three-bin fields through both readouts, singleton seeded identity, dynamic sampler-call counting, and readout-overflow failures after random draws. Adding a permanent late-overflow RNG regression would strengthen the retained integration test, but no failure was observed.
