## 2. Continuous aperture and MTF interpretation

The documentation and implementation keep the finite discrete PSF OTF separate from the optional ideal continuous square-aperture sinc reference. `opticalMtf` evaluates the complex DFT using the explicit origin and physical sampling, reports its magnitude, and labels the aperture as `ideal_continuous_square_analytical_reference` with a warning against applying averaging twice. Tests include a separate direct DFT, an independent binomial cosine identity, origin-sensitive complex phase, and the full sinusoid pipeline.

For this demo, let `p=6e-6 m`, source spacing `d=p/2`, frequency `f=1/(8p)`, and `sinc(z)=sin(pi*z)/(pi*z)`:

- Source-cell sinc `sinc(fd) = 0.9935868511442058`.
- Binomial optical response `cos²(pi*f*d) = 0.9619397662556434`.
- Target square-pixel reference `sinc(fp) = 0.9744953584044327`.
- Combined optical × target aperture response `0.9374058372807694`.

The source starts as the exact cell averages of a continuous sinusoid. Averaging two adjacent half-pixel cells adds `cos(pi*f*d)`, and `sinc(fd) cos(pi*f*d) = sinc(fp)` (independent evaluation `0.9744953584044326`). Thus the demo's single target-aperture factor follows from the chosen aligned fixture mathematics; it is not a universal assertion about arbitrary discretized samplers. The code applies no extra MTF multiplier to the simulated image.

Two additional independent wrong-model gaps on the retained row were `8.8353186222075e11` density for applying the target aperture twice and `2.235982888885e11` for treating the source-cell averages as point samples. Both greatly exceed rounding differences. The documentation correctly avoids presenting this synthetic finite kernel or ideal geometric aperture as measured ARRI optics, or fill-factor-dependent aperture shape.
