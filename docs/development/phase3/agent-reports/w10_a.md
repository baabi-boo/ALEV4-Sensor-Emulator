## First Phase 4 commit recommendation

Make the first commit the **component-order/configuration design and parameter-source register** specified by the plan's final paragraph. Freeze a separate opt-in schema, full-grid realization identity/ROI association, component placement/units, deterministic map validation, and persistent/frame RNG lifecycle before production edits. The immediately following first implementation slice should contain only the strict configuration/identity layer, explicit fixed-map selection, disabled delegation, and its acceptance tests.

Three concrete integration choices must be settled in that design; the plan acknowledges them rather than supplying callable APIs:

1. **Configuration ingress and output semantics.** `createBaselineSensor`, `createDualGainSensor`, and `simulateSpatialExposure` reject unknown fields; `bindSensorGeometry` requires complete existing schemas. Choose a separate explicit interface/configuration and preserve old formats. Define separate baseline-photo, PRNU-adjusted-photo, dark, and total-charge quantities before repurposing any expected-electron field.
2. **Exact disabled RNG compatibility.** Single gain skips its Gaussian draw at zero read-noise RMS; dual gain always draws both Gaussian arrays in high/low order. Disabled delegation must preserve those differences and all earlier results. Do not achieve component isolation by changing legacy streams.
3. **Persistent map identity and support.** Specify how nonspatial single/dual calls associate with the full grid, reject mismatched shapes/identities, and define allocation/range limits before materializing maps. Preserve immutable caller structures. No supplied PRNU map should be silently normalized.

## Acceptance for the first implementation slice

- Exact disabled/absent identity for single, dual, and both spatial wrapper modes: all existing output arrays/flags and same-runtime seeded behavior, including zero/nonzero shot/read-noise settings and existing artifact identities.
- Deterministic full-grid versus ROI map equality for all Bayer patterns and four ROI parities, including odd/nonsquare and edge crops; no mutation of readout, geometry, map, or caller RNG state.
- Fixed realization unchanged across different frame seeds; explicit component seeds/lifetimes; isolation from unrelated component enablement; success and early/late failure restoration.
- Strict rejection of unknown fields, mismatched geometry/maps, nonfinite values, invalid seeds/rates/covariance, and unsupported numerical/allocation ranges. Inert disabled configuration must not silently conceal malformed inputs under an undocumented policy.
- Rerun and retain the preserved baseline on the selected clean starting revision before production changes, then preserve complete Phase 1–3 acceptance when validating the implementation. Historical receipts establish entry evidence but do not substitute for this future run.

The next physics slice should start with small explicit maps: verify `mu_photo = response_multiplier * mu_baseline_photo` and `mu_dark = dark_rate * exposure_s`, zero endpoints and analytic scaling, then finite-sample mean/variance and shared dual covariance. Declare separate-versus-combined Poisson draws and dark-noise policy independently of the photo-shot toggle. Confirm total charge drives one physical saturation event; fixed electronic offsets remain exposure-independent and downstream of that well.
