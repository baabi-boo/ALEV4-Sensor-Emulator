## Concrete changes

### `matlab/+alev4/bindSensorGeometry.m`

Removed the unconditional `sensorGrid` call that previously ran immediately after geometry validation, even when the readout was incomplete or invalid. Binding now validates the complete single/dual configuration through the unchanged constructors and `requireComplete` helper, then reads `active_roi(3:4)` and shifts the four-element Bayer tile according to the one-based ROI row/column parity.

The operation therefore has no active-axis coordinate allocation. The derive/validate behavior, spatial fields, canonicalization, conflict errors, nested dual structure and nonspatial settings remain covered by existing exact equality and seeded integration checks. Full coordinate representability remains checked by `sensorGrid` when a caller actually requests coordinates or samples an exposure. Geometry descriptor validation still runs before readout validation.

### `matlab/+alev4/simulateSpatialExposure.m`

After `validateSpatialIrradiance` and the exact input-plane/readout-bin association check, the wrapper applies:

```matlab
if prod(geometry.active_roi(3:4)) > 1e8/bands
    error('ALEV4:InvalidSpatialSampling', ...);
end
```

Both the ROI and positive band count are validated before this comparison. The division form matches the already repaired resampler guard and avoids computing an unnecessarily large spectral-cube product. Oversized requests fail before either optics branch and before resampling. The output limit concerns the active ROI, not the full-grid descriptor. Input normalization and spectral validation retain their previous precedence.

### `matlab/tests/test_phase3_geometry_edges.m`

Added two groups, increasing this suite from eight to ten:

1. **Large descriptor binding:** single/dual derive and validate cases for horizontal, vertical and near-limit square ROIs; all four full CFA patterns with independently listed expected crop patterns; exact preservation of nonspatial settings; rejection of omitted single/nested-dual fields, invalid complete QE, and conflicting existing bindings.
2. **Output limit before optics:** horizontal and vertical 100,000-pixel ROIs, 1,001 input spectral values, both readout schemas, derive/validate, and pre-PSF/post-optics. An otherwise valid two-tap PSF cannot fit the one-cell input, proving the oversized-output error takes precedence over optical support. Controls admit exactly 100 million samples to the optical-support check, retain the spectral-mismatch error for inconsistent bands, and successfully simulate a one-pixel active crop from each large full-grid descriptor. Caller RNG state is unchanged.

No test allocates the prohibited 100-million-sample output. Negative axes are bounded at 100,000 even if coordinate allocation regresses. The exact-limit control fails at deliberately insufficient optical support before output allocation.
