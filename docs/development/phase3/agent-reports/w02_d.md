# Wave 2 D — conservative sampling implementation

Assignment 10/60, wave 2/10. Implemented only the three assigned production files after root reported the independent Slice 3A geometry gates passing (12 + 8 groups). No existing readout code or dependency pins changed. This is focused implementation evidence, not complete Phase 3 acceptance.

## Implemented APIs

- `createSpatialGrid(overrides)`: canonical fields `schema_version='1.0'`, `x_edges_m`, `y_edges_m`, `units='m'`, `sample_semantics='cell_average'`. Strict unknown-field, shape, finite increasing edges, finite widths/extents and representable positive cell-area checks. Accepted numeric vectors normalize to dense double rows. Default edges match the existing generic geometry.
- `[irradiance,grid]=validateSpatialIrradiance(irradiance,grid)`: finite nonnegative numeric H-by-W-by-K input with H/W exactly matching cells, K preserved and at most 100 million numeric samples. One-bin sparse input becomes dense double. No spectral interpolation; the wrapper must bind K to explicit readout wavelength bins.
- `[sampled,report]=resampleSensorIrradiance(irradiance,input_grid,geometry)`: exact represented-coordinate coverage and per-axis sparse area-overlap fractions. Output remains photon-irradiance density. No area, exposure, QE, bin-width, fill-factor or random-number operation is applied. Exact source-aligned subgrids return a direct copy/slice. Other cases choose the smaller of the two separable intermediate arrays, preventing singleton shape changes from allocating a huge cross-shaped intermediate.

Descriptors permit at most 100 million spatial cells; source and output cubes permit at most 100 million numeric samples. These are support limits, not performance guarantees. Coordinates are not snapped or extrapolated. Unsupported positive-overlap weight underflow, row-sum inconsistency, and nonfinite output reject explicitly.

## Report semantics

The descriptive report includes units, sample/coverage policy, source/target physical bounds, active ROI/CFA, spectral-plane count, identity/aligned-copy flags, axis nonzero counts, row-sum residuals, and represented target-pitch discrepancy. `source_integral`, `source_crop_integral`, and `target_integral` each contain `status` and `values`. Values are area-integrated density per spectral bin, in photons/(s nm). Optional diagnostics that overflow or underflow are explicitly marked `unavailable_numeric_range` with an empty values array; a finite average itself can still be valid. Conservation is not asserted merely because a producer emitted this metadata.
