## Concrete defects discovered and resolved

1. **Incomplete readouts silently manufactured settings.** The binding helper
   documented complete validated configurations but accepted a struct containing
   only schema_version, filling spectral/electronic defaults in the constructor.
   A default-geometry validate invocation therefore passed without a caller
   explicitly supplying the purportedly validated settings. Root added recursive
   complete-field checks. Tests reject missing top-level, nested sensor, high-gain
   and merge fields in both derive and validate modes.
2. **Trailing newline accepted in source IDs.** Octave's regular expression `$`
   anchor matched before a final newline, so `sprintf('SOURCE\n')` passed the
   source identifier validator. Root replaced it with a strict end anchor. The
   new test rejects trailing newline, embedded tab/NUL, whitespace, path syntax,
   duplicate IDs, invalid shapes, excessive count, and overlong identifiers.
