## Fifteen independent named groups

1. Numeric representation normalization, stable coefficient revalidation, and
   explicit source/boundary labels. The documented near-unit mass tolerance
   preserves supplied values rather than repeatedly renormalizing them.
2. Exact identity data/grids and complete seeded single/dual readout equality.
3. Nested scalar convolution with a nonsymmetric 2-by-3 kernel and all six
   origins, checking physical edges, retained indices, and each halo count.
4. Impulse orientation, two-axis translation, and full retained interior mass.
5. Explicit cropped energy loss (boundary impulse retains 0.25, not 1), plus
   full declared support even for zero-valued kernel border coefficients.
6. Distinct per-wavelength kernels and independent plane-specific complex DFT,
   exact wavelength association, missing/changed/reordered mapping rejection.
7. Flat fields in both ordinary and large density units, nonnegative linearity.
8. Independent scalar sine/cosine DFT across 2D positive/negative frequencies
   and all asymmetric origins; physical Nyquist and units checks.
9. Separable binomial cosine oracle, DC unity and Nyquist zeros.
10. Origin-dependent complex phase with invariant magnitude, and independent
    continuous square-aperture sinc values with the explicit analytical caveat.
11. Exact continuous-cosine input cell averages through PSF, 2x overlap averaging,
    spectral integration, and RAW quantization. Its oracle multiplies the
    discrete optical transfer by the final physical aperture response exactly
    once, avoiding duplicate pixel-averaging attenuation.
12. Hand-computed edge profile [0.125,0.875,1] through blur plus averaging,
    followed by independently specified BGGR QE, area, fill, time and bin width.
    Also rejects an extra PSF on already post-optics data.
13. Malformed kernels, origins, spacing, source metadata, wavelength banks,
    frequency types/ranges, excessive output shape and aperture values reject.
14. Nonuniform/mismatched grids, oversized support, positive optical underflow,
    finite-input convolution overflow, and phase-range overflow reject.
15. Caller RNG and input arrays/structs survive success and failure unchanged.

The test file uses scalar loops and closed-form expectations rather than
calling production convolution/sampling to generate its reference values.
