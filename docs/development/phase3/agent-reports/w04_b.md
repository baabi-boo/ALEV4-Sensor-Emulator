## Runner coverage

The runner, setup, and source-provenance helper are copied byte-for-byte into
owned temporary repositories whose paths contain spaces and an apostrophe.
Temporary ISET path sentinels fail if called; they only permit the unchanged
setup path checks to reach controlled prerequisite-return scenarios.

A full fixture run produces the complete prior success record. Every
subsequent scenario starts with that full record plus an old-evidence marker.
Coverage includes:

- Core-only completion with upstream directories, the ISET gate, and Phase 2
  runner absent; it never becomes full acceptance.
- Missing upstream dependencies, missing ISET/Phase 2 entrypoints, false,
  skipped, absent, or malformed prerequisites, and preserved Phase 1/ISET
  failures.
- Missing numerical suites, late assertions, incomplete/empty/nonfinite/
  fractional inventories, unpassed or missing test flags, blank names,
  duplicate names, and malformed status/pass types.
- Initial write refusal, which leaves the previous success bytes unchanged
  while the current process fails.
- Final write refusal, which leaves the freshly invalidated running/false
  report while the current process fails.
- An error after the runner returns a full fixture success, proving that
  current process failure can coexist with successful report bytes.

## Production findings and disposition

1. Report pass flags originally used isequal(value,true). GNU Octave 9.4.0
   treats numeric 1 as equal to logical true. Cell-wrapped passed text could
   also satisfy strcmp. Reported this to root; root added typed logical-scalar
   and character-row status checks, together with preserved Phase 1/ISET
   prerequisite checks. The new native scenarios pass against that fix.

2. The orchestrator originally resolved output_root before checking
   is_symlink(), allowing a dangling symlink to a nonexistent destination to
   bypass the fresh-output check. Reported this to root; root added the
   pre-resolution exists/is_symlink guard. The focused dangling-symlink test
   passes and confirms the destination remains absent.

The root agent owns both production fixes. No additional production issue was
