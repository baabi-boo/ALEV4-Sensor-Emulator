## Proposed APIs and input contract

```matlab
grid = alev4.createSpatialGrid(overrides);
[sensor_irradiance, report] = ...
    alev4.resampleSensorIrradiance(irradiance, grid, geometry);
```

Recommended grid fields:

| Field | Contract |
| --- | --- |
| `schema_version` | Separate spatial-grid version, e.g. `'1.0'` |
| `x_edges_m` | Strictly increasing finite real vector of cell edges; normalize to a dense double row |
| `y_edges_m` | Strictly increasing finite real vector of cell edges; normalize to a dense double row |
| `sample_semantics` | Exactly `'cell-average'`; no silent point-sample conversion |

Use explicit edge vectors as the canonical first representation. A uniform-grid convenience constructor can produce these vectors; there is no need to maintain two independent definitions of a grid's extent. Require at least two edges on each axis, which supports singleton dimensions. Unknown fields reject. Do not sort, deduplicate, infer edge values from centers, or silently clip malformed inputs.

The irradiance shape is `(numel(y_edges_m)-1)` rows by `(numel(x_edges_m)-1)` columns by `K` spectral bins. For one spectral bin, MATLAB/Octave may represent it as a 2-D matrix; `size(input,3)==1` handles that. Accept only real finite nonnegative numeric values. Reject shape mismatches, empty bins, trailing non-singleton dimensions, NaNs, infinities, complex values, and logical values if retaining the existing core's numeric-input contract. Sparse one-bin matrices may be normalized to dense double just as `integrateExposure` does.

The sampler preserves bin index exactly; it does not interpolate wavelengths. The exposure wrapper must verify that `K`, wavelength centers, and widths match the readout configuration and bind that association into provenance. Grid validation need not duplicate the entire spectral configuration.

Target edges must come exclusively from validated `sensorGrid(geometry)` for the active ROI. No separate output size or pitch override belongs in the sampler. Full target footprints must lie inside the source rectangle. Missing coverage is an error, including on a single edge or corner. There is no extrapolation, padding, partial-pixel fill, or boundary renormalization in this first API.

## Operator and exact mathematical conservation

For destination column interval `D_j=[d_j,d_(j+1)]` and source column interval `S_i=[s_i,s_(i+1)]`, define:

```text
Lx(j,i) = max(0, min(d_(j+1),s_(i+1)) - max(d_j,s_i))
Wx(j,i) = Lx(j,i) / (d_(j+1)-d_j)
```

Construct the same normalized overlap matrix `Wy` for rows. For each spectral plane:

```matlab
out(:,:,k) = Wy * double(input(:,:,k)) * Wx.';
```

This is the exact area average for the declared piecewise-constant source model, up to floating-point arithmetic. The two factors are dimensionless fractions. Do not divide by source-cell areas: the input values are already densities. Do not multiply the output by the target area: the next stage does that once.

On complete support each weight row sums to one mathematically. Consequently the operator preserves constant fields, remains nonnegative, is linear, and returns values inside the source range. Check row sums within a floating-point accumulation bound; do not normalize them after construction to hide an uncovered footprint or inconsistent edge arithmetic.

For equal source and destination outer extents, the area-weighted sum of each output spectral plane equals the area-weighted sum of the source plane. For an active crop, the correct source-side reference integrates the source cells only over their intersections with that crop. Comparing crop output energy to the complete source image is wrong.

Use represented target edge differences in the overlap formula and conservation diagnostic. The geometry layer must separately guarantee they represent its nominal square pitch adequately; `integrateExposure` still uses nominal `pixel_pitch_m^2`. Report/check the representational discrepancy rather than silently changing the sensor pitch. A coordinate system with such a large absolute origin that micrometre edges lose meaningful precision should reject at geometry validation.

## Sparse construction and identity

Construct per-axis weights with a monotone two-pointer interval sweep. Sorted nonoverlapping one-dimensional partitions need at most approximately `Nsource + Ndestination - 1` positive intersections over a common region. Store only positive overlaps in `sparse(row_indices,column_indices,values,ndst,nsrc)`. A dense `Ndst` by `Nsrc` matrix is unnecessary and can make modest full-frame dimensions impractical. This is separable geometry, so never build a full two-dimensional pixel-to-cell weight matrix.

Before allocation, enforce the declared source/destination dimension and element-count bounds with division-based overflow-safe checks. Distinguish a supported format limit from a practical memory or throughput guarantee.

If both source edge vectors exactly equal the active target edge vectors and the shapes match, return the normalized input without arithmetic. This makes the identity spatial path byte-identical at the irradiance boundary and permits existing seeded single/dual RAW identity regressions. An exactly aligned source subgrid can likewise be sliced directly. Do not select identity using a broad approximate-equality tolerance: a real subpixel offset must be sampled.

## Numerical and error-path safeguards

1. Require every computed width and overlap to be finite. Finite endpoint values alone do not ensure finite differences (e.g. `[-realmax,+realmax]`).
2. Require strictly positive cell widths after conversion to double. Integer values above exact-double range can collapse after conversion; validate the canonical representation.
3. Reject target or source edge collapse from large origins or extreme pitch before dividing by a width.
4. Use local endpoint ULP scales for roundoff checks, never a global `eps(max(1,...))` that creates a huge absolute tolerance relative to a nanometre-scale grid. Never silently treat a measurable coverage gap as covered.
5. If endpoint snapping is eventually needed for independently constructed nominally coincident grids, make the tolerance and changed coordinates explicit in the contract/report and test it separately. Strict coverage and edges produced by a common constructor are safer for the first release.
6. Verify each positive overlap produces a finite positive normalized weight. A positive overlap that underflows to zero is an unsupported numeric range, not exact zero support.
7. Check output finiteness and nonnegativity. Nonnegative inputs/weights should not need a negative-value clamp. Overflow must raise an error rather than produce an apparently valid sensor input.
8. Keep optional energy diagnostics numerically safe: a huge total-area integral can overflow even when the per-pixel average is representable. Either reject that diagnostic's unsupported range explicitly or report it as unavailable; do not make an infinite value a passing conservation result.
9. Geometry, validation, weight construction, and sampling must consume no RNG state, including on errors. Do not add a seed argument to deterministic helpers.

## Independent test oracles

### A. Nonuniform edges and a subpixel crop

Take metre units merely for an exactly representable arithmetic fixture:

```text
x_edges = [0,1,3]
y_edges = [0,2,3]
input   = [ 2, 6;
           10,14 ]
```

For a 2-by-2 target with pitch 1 and outer origin `(0.5,0.5)`, independently integrate the four target rectangles:

```text
expected = [4,6;
            8,10]
```

The crop's integral is 28, not the whole source's integral 66. The four source-cell contributions to the crop are `1.5`, `13.5`, `2.5`, `10.5`. These hand values detect transpose errors, use of source instead of target normalization, and incorrectly comparing whole-image energy for a crop.

For a full 3-by-3 unit-pitch target from `(0,0)`, expected rows are `[2,6,6]`, `[2,6,6]`, and `[10,14,14]`; the output sum is exactly 66.

### B. Noninteger scale ratio

Use a one-row input with x edges `[0,0.6,1.4,2]` and values `[1,3,5]`. Sampling onto two unit-width targets produces `[1.8,4.2]` within an ULP-scaled tolerance. Duplicate across independently weighted rows to exercise both axes. Repeat after translating all edges by the same exactly representable offset.

### C. Spectral independence and physical-unit guard

Use multiple planes with distinct constants and separate spectral impulses. No output plane may contaminate another. A spatial constant field with pitch `p`, exposure `t`, fill `a`, bin width `d`, QE `q`, and density `F` must yield `F*p^2*t*a*d*q` electrons at the selected CFA channel. Include a deliberately area-integrated wrong input whose result differs by `p^2`; ensure the test would fail a sampler that multiplies by area. Changing fill factor must scale electrons once while leaving sampled irradiance unchanged.

### D. Discontinuity refinement

For a known step at physical coordinate `a`, construct exact source cell averages analytically, using the illuminated fraction of each cell. Refine the source edges while holding target footprints fixed. Retain the actual maximum target-average error and source step-crossing-cell width at each level. For a bounded step, error is confined to partially included source cells at target boundaries, giving a conservative first-order envelope proportional to `jump * max_cell_width / pixel_pitch` (at most two boundary cells per one-dimensional target). Do not assert strict monotonicity for arbitrary grid phases; error may be exactly zero for some alignments and nonzero at another refinement. Test the stated envelope and eventual resolution, not a visually chosen tolerance.

### E. Required adversarial cases

All-zero input; distinct constants per spectral plane; singleton dimensions; odd/nonsquare grids; an impulse in each corner; identity and exactly aligned crops; every crop/CFA parity through the wrapper; exact edge touch; one missing edge/corner; reversed/repeated edges; NaN/Inf/complex/logical inputs; width overflow; edge collapse; unsupported dimensions; bad spectral count at wrapper; preservation of inputs and RNG on success/failure.

### F. Test tolerances

Use exact equalities for identity and binary-fraction hand fixtures. For computed overlap mixtures, use a bound based on local coordinate representation plus the number of positive terms in each weighted sum (`gamma_n = n*eps/(1-n*eps)` for a simple forward-error estimate). Scale the absolute output tolerance by the input magnitude and overlap-error bound, with an explicit zero-input case. A fixed relative tolerance without an absolute zero case is unsuitable; a large arbitrary absolute tolerance can conceal unit errors.

## Recommended diagnostics/provenance

The report should identify method `'piecewise-constant-area-overlap'`, unchanged input/output density units, source and active target edge vectors, exact active ROI, output shape, spectral-plane count, coverage policy `'require-full-footprint'`, input sample semantics, identity fast-path usage, per-axis weight nonzero counts, and optional conservation/row-sum numerical diagnostics. These are descriptive results; independent artifact verification still needs to recompute weights from actual source data and geometry rather than trusting a `conservation_passed` flag.

PSF belongs before this operator and before the Bayer response. Its trimmed, fully supported output grid becomes this operator's input grid. An ISET optical image has already undergone optics and must not receive an implicit second PSF. Point-sampled ISET values require their own documented conversion approximation before using this cell-average API.
