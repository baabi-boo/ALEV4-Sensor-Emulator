# Wave 2 C — assignment 09/60: spatial artifact design

Completed design work only. Read AGENTS.md, Phase 3 design/plan, existing
Phase 1/2 writers/readers, strict JSON codec, source provenance, Python verifier,
and relevant architecture/roadmap. Inspected source/dependency state. No
production code or dependencies were changed, and no numerical tests were run.

Created `docs/PHASE3_ARTIFACTS.md` as the strict 1.0 higher-level spatial bundle
contract. Confirmed wrapper fields/options with root and PSF fields with the
optics implementation agent.

Decisions:

- New fixed directory layout and `spatial.json`; unchanged nested single/dual
  readout formats at fixed `readout` stem.
- Retain input, post-PSF, sampled density, expected electrons, and optional PSF
  coefficients as explicit little-endian float64 files, with spectral planes
  then rows as the ordering and retained singleton dimensions.
- File descriptors bind actual bytes through SHA-256, exact length, type,
  shape and units. Release receipt hashes the spatial manifest itself.
- Require exact pre-PSF/post-optics operation sequences, no implicit second
  blur, strict geometry/readout binding, complete configuration and source IDs.
- Keep accepted shared JSON codec unchanged: Phase 3 wire adapters convert
  geometry/PSF source cells into id001... keyed objects and operation sequence
  into step001... objects. Store 3D kernels in psf.f64, avoiding unsupported
  N-D JSON serialization and numerical precision loss.
- Recompute optics, supported grid, overlap averages and spectral charge;
  independently verify deterministic readout bytes and observed dual merge.
  Hash consistency alone is not a numerical proof or authentication.
- Require bounded strict JSON decoding (including legacy single readout
  metadata), regular disjoint files, no-overwrite sibling staging publication,
  owned cleanup, and fresh-process nonaliased repeats.

The document is explicitly a design contract, not an implementation or
acceptance claim. Implementation agents must reconcile actual API behavior
and recorded numerical tolerance choices with this contract before release.
