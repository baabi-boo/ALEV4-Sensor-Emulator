## Committed-test coverage

The new suite contains 14 named test groups:

1. Independent two-band bilinear-polynomial cell-average oracle and complete-area integral.
2. Cropped bilinear integral with all native interpolation knots retained.
3. Malformed point data/axes, coverage gaps, missing knots, and shape rejection.
4. Extreme representable constant scales, sparse-input normalization, explicit numeric-range failure, and RNG preservation.
5. Genuine uniform scene, optical computation, and native sensor comparison.
6. Genuine ramp scene, optical computation, and native sensor comparison.
7. Genuine checker scene, optical computation, and native sensor comparison.
8. Genuine edge scene, optical computation, and native sensor comparison.
9. Coarse wrong-model controls plus separate source-grid and native-subpixel refinement sequences.
10. Physical/CFA binding, retained spectral bins/QE, density units, and explicit absence of a second PSF.
11. Existing session/preferences/RNG restoration after each successful fixture and a deliberately saturated failure.
12. Absent global session/preferences restored after both success and post-initialization failure.
13. Unsupported arguments and an actual temporarily unavailable `sensorCompute` dependency fail explicitly.
14. Exact same-runtime repeatability and independent exposure-linearity checks.

Fixture tests recompute the reported project/native residuals from retained
arrays, independently integrate retained sampled irradiance spectrally through
scalar loops, verify deterministic ADC bytes, and inspect physical and
provenance fields. They check actual optical variation so differing Bayer
colors cannot substitute for a nonuniform scene. Coarse checker/edge controls
must differ by more than 1%, and both refinement sequences must improve by
more than tenfold. Strict monotonic improvement at every intermediate grid is
not required.

The missing-dependency case removes the directory containing `sensorCompute`
from the current path, confirms that the function is actually unavailable,
requires `ALEV4:MissingISETCam`, and restores the original path with cleanup.
No upstream file is changed. The suite also preserves unrelated preference
groups and restores its caller's original RNG and ISET state on exit.
