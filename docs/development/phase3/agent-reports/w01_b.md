- Publisher: ARRI.
- Title: **ALEXA 35**, Technical Data.
- Exact current URL: https://www.arri.com/en/cine-systems/cine-cameras/legacy-cine-cameras/alexa-35
- Also indexed under the older URL: https://www.arri.com/en/camera-systems/cameras/alexa-35
- Revision: no technical-data revision/date supplied on the inspected webpage; retain retrieval date rather than inventing one.
- Sections: Sensor Type; Sensor Maximum Number of Photosites and Size; Photosite Pitch; Sensor Active Image Area (photosites/dimensions).
- Directly published: Bayer CFA sensor type; maximum photosites 4608 columns × 3164 rows; physical size 27.99 mm × 19.22 mm; photosite pitch **6.075 micrometres**. The pitch is explicitly published, not derived by dividing rounded dimensions.
- Open Gate 4.6K 3:2 is listed at 4608 × 3164. Its mode-specific dimension line uses the more coarsely rounded 28.0 × 19.2 mm.
- No measurement tolerance, uncertainty interval, top-left Bayer ordering, effective-QE samples, fill-factor value, optical-black margin, or PSF/MTF samples is supplied by these inspected sections.

## Safe geometry profile

A geometry-only opt-in `alexa35_open_gate` profile can use:

```matlab
full_grid_size = [3164 4608]; % rows, columns; published image counts are width × height
active_roi = [1 1 3164 4608];
pixel_pitch_m = 6.075e-6;
origin_xy_m = [0 0];         % explicitly assumed image-coordinate convention
full_grid_cfa_pattern = 'RGGB'; % if a default is needed, explicit assumption
```

Prefer requiring `full_grid_cfa_pattern` as an explicit choice for target-labelled profiles, or attach an unavoidable assumption record. Name/document the profile as sourced **Open Gate geometry** only. Do not call the grid the complete physical die or infer masked pixel margins. Retain compact generic defaults; merely constructing this profile should not allocate a 14.58-million-pixel image.

Independent arithmetic: 4608×6.075 µm = 27.9936 mm; 3164×6.075 µm = 19.2213 mm. Differences from the separately printed dimensions are +0.0036 mm and +0.0013 mm, respectively. Both fit half of a 0.01-mm display step if conventional rounding is the interpretation. Such a ±0.005-mm **rounding consistency interval** is a model interpretation of printed decimal precision, not a manufacturer measurement uncertainty. The more coarsely rounded 28.0×19.2-mm Open Gate line also agrees at its printed precision.

Other crop mode counts are published, but crop starting indices and Bayer phase are not established by this audit. Avoid silently centered target-specific crop presets until those offsets are sourced or explicitly classified as assumptions. In particular, odd column count 2743 in 2.7K 8:9 makes a centered integral offset ambiguous.
