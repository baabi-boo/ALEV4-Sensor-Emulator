## Assumed map and sweep definitions

For full-grid one-based row `r` and column `c`, deterministic fixed maps are:

- PRNU `1 + 0.01*(r-3.5) + 0.005*(c-4.5)`, dimensionless, with no normalization.
- Dark rate `2 + 0.5*r + 0.25*c`, electrons/photosite/second.
- Shared offset `2*(r-3.5) + (c-4.5)`, electrons.
- Single offset `0.25*(r-c)`, electrons.
- High-path offset `0.5*r - 0.25*c`, electrons.
- Low-path offset `-0.25*r + 0.5*c`, electrons.

The explicit reference temperature is 293.15 K; there is no temperature law.
The deterministic fixed-map photoelectron-rate field is
`10000 + 250*r + 500*c`, electrons/second before PRNU. Input density is this
rate divided by `pixel_pitch_m^2 * bin_width_nm`, in
photons/(m^2 second nm). Dark frames use exactly zero input density.

The single/dual exposure and electronic-gain sweeps use the row-repeated
baseline photoelectron-rate profile
`[0 4000 12000 24000 40000 70000 120000 220000]` electrons/second.
Their PRNU is one, dark rate is zero, shot/read noise is disabled, and a shared
fixed offset of -256 electrons is supplied in column 1 only. The physical
full well is 3000 electrons. Single baseline electronics are 1 DN/electron,
32 DN black offset, and 10 ADC bits. Dual baseline electronics are high gain
4 DN/electron and low gain 0.5 DN/electron, each with 64 DN black offset and
12 ADC bits; the merge interval is [600,900] electrons. For the dual gain
sweep, both gains scale together and the merge interval divides by that scale.

These executed settings include lower ADC clipping, single and
high-path upper ADC clipping, a 700-electron dual handoff point, and physical
well saturation. At dual scale 4, the 2200-electron input also clips the low
path's upper ADC rail before physical saturation. Actual generated masks passed
the named fixture coverage assertions for all these cases.

The sequence has one identity, `ASSUMED-P4-DEMO-SEQUENCE-v1`, and sequence seed
4294967200. Seeds are `mod(sequence_seed + 64*(absolute_index-1), 2^32)`.
Primary, reset and continuation calls use identical mixed dual input and
configuration at the same absolute indices. EI changes only the labels above;
there is no exposure or electronic-gain mapping. Expected equality is the
entire corresponding frame result, not only RAW. All fixed parameters remain
synthetic, `synthetic=true`, `calibrated_alev4=false`, with runtime/version and
observed Git provenance retained. Cross-runtime random-stream identity is not
claimed.

## Demo publication and failure contract

The demo rejects existing destinations (files, directories and dangling links),
dot segments, repeated/trailing separators and symbolic-link ancestors. It can
create missing ordinary parent directories. An exclusively created sibling
stage receives an initially incomplete summary before any export. Only 24
completed exporter calls, 24 completed native reader calls and complete result
equality permit completion status. Summary numbers use 17-digit binary64
encoding, and summary bytes are read back exactly. The stage publishes by
directory rename, with a subsequent ownership/summary check.

Stage creation requires both successful `mkdir` and an empty diagnostic;
successful `mkdir` of a preexisting directory never establishes ownership.
Cleanup checks the directory identity through Octave `lstat` or a MATLAB JVM
file key, and only removes the directory this invocation owns. Existing output
is rejected and preserved, including a prior successful summary: it is never
adopted as success for a new attempt. Incomplete staged state cannot leave a
published successful summary. Concurrent writers remain unsupported.

The staged export/publication and Java file-key branches have **not executed**
in this task. Their successful operation is a later integration obligation,
not implied by passing the preflight checks.
