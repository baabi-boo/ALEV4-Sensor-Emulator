## Spatial implementation

The seven-argument API accepts the same optional eighth-argument options as
`simulateSpatialExposure`. Geometry and the explicitly supplied model are
validated without randomness. A disabled model directly returns the legacy
spatial result without added fields or modified readout content.

For enabled operation, the wrapper obtains one complete legacy spatial
baseline, including its valid legacy readout. It then calls
`simulateStructuredExposure` exactly once on that baseline's
`sampled_irradiance`, canonical bound configuration, and canonical geometry.
The baseline's sampled charge never contributes to structured collected or
stored charge. The core's separate structured artifact identity and all its
retained physics remain intact.

The enabled wrapper sets `result_kind='spatial_exposure'` and adds:

| Field | Meaning |
| --- | --- |
| `spatial_baseline` | The intact legacy result, equal to a separate legacy invocation with the same arguments. |
| `spatial_baseline_role` | `verification_context_only`. |
| `spatial_operation_order` | Legacy optics/averaging stages followed by the core structured operation order. |

The core `operation_order` remains unchanged. The legacy spatial validator
accepts `spatial_baseline`, including stochastic readout replay, and rejects
the new structured outer result. Existing artifacts and validators are not
modified to accommodate the new semantics.

## Sequence implementation

`simulateNoiseSequence(input, readout, exposures_s, sequence_seed, model,
geometry, options)` accepts a nonempty numeric exposure vector. One exposure
is required for every frame; a scalar requests exactly one frame. All frames
use the same input, canonical configuration, geometry, and supplied fixed
model. Every frame calls the structured API once, preserving its component
stream policy and its explicit disabled dispatch.

The only accepted option fields are:

| Option | Contract |
| --- | --- |
| `frame_indices` | One strictly increasing integer per exposure, each in `[1,2^26]`; gaps allowed, duplicates and reversed order rejected. |
| `start_frame` | First consecutive absolute index, default 1; cannot coexist with `frame_indices`. |
| `ei_label` | `[]` for absent labels, a positive finite numeric scalar replicated as metadata, or one positive finite numeric label per frame. |

Seeds must be integers in `[0,2^32-1]`. The exact binary64 schedule is
`mod(sequence_seed + 64*(absolute_frame_index-1), 2^32)`. Bounds are validated
before converting accepted values to doubles or applying modular arithmetic.
All intermediates stay below `2^33`. There is no RNG-derived map creation,
elapsed-time interpretation, or hidden reset/continuation state.

The sequence envelope uses `ALEV4-SYNTHETIC-STRUCTURED-NOISE`, schema `1.0`,
and `result_kind='independent_frame_sequence'`. It records the canonical
configuration, geometry and `noise_model`; `sequence_seed`, `frame_count`,
absolute `frame_indices`, `frame_seeds`, `exposures_s`, `ei_label`; the cell
array `frames`; `temporal_policy='independent_frames'`; the seed schedule;
runtime and same-runtime/version reproducibility policy; and explicit
synthetic/uncalibrated classification.

`structured_noise_enabled` and `frame_result_kind` explicitly describe
disabled sequences. Their frame cells contain unchanged legacy single- or
dual-gain results, while the sequence itself keeps the separate new envelope.
EI never reaches the exposure or readout call and never changes physical
exposure, gain, QE, noise, clipping, or merge behavior.

A preliminary size check includes input samples and active pixels. After the
first frame, the wrapper counts its actual retained numeric/logical values
recursively, including full fixed maps, input, active maps, component arrays,
readouts and numeric metadata. The complete retained sequence is bounded at
100 million numeric/logical values before allocating and simulating its
remaining frames. This deliberately conservative count includes repeated
fixed-map fields even when runtime copy-on-write may share their storage.
It is a numerical-size limit, not a memory or throughput guarantee.

Both public wrappers preserve caller RNG state through `onCleanup`, including
late failure after a sequence has already simulated earlier frames.

## Limits and next verification

The enabled spatial API intentionally requires its legacy verification
baseline itself to be valid. For example, an otherwise unsupported legacy
Poisson mean is not bypassed merely because PRNU might reduce the structured
expectation. This follows the requested intact validated-baseline contract.
Its extra legacy simulation is verification work; only the separate
structured exposure supplies the reported physical charge.

The new wrappers have no mutable sequence state and no correlated temporal,
rolling-shutter, firmware EI, or measured flicker model. Distinct schedule seeds
are a declared synthetic PRNG policy rather than mathematical evidence of
independence. Stochastic crop/full-frame identity is not promised.

The next gate is integration into the parent's independent deterministic,
statistical, invalid-input, artifact, fresh-process, and runner-failure suites.
No complete Phase 4 acceptance, new CI pass, artifact-export acceptance,
cross-runtime stream equivalence, native MATLAB pass, or physical calibration
is claimed by this task.
