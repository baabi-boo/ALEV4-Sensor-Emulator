# Wave 1 / agent B — API, RNG and integration audit

## Scope and evidence

Read-only production-code audit of `AGENTS.md`, `docs/PHASE4_PLAN.md`,
`docs/ARCHITECTURE.md`, the single/dual/spatial simulation entrypoints,
constructors, geometry binding, Poisson sampling, merge, and existing artifact
validation. No numerical execution or implementation pass is claimed by this
report. The starting implementation is the accepted Phase 3 layer.

## Recommended extension boundary

Keep the existing Phase 1/2 readout configurations and entrypoints unchanged.
Their constructors reject unknown fields, and `bindSensorGeometry` requires
complete exact schemas. New noise fields inside `.sensor` would break this
contract or silently change the meaning of an existing artifact.

Use an explicit opt-in noise configuration and a new wrapper, with interfaces
along these lines (names are proposals, not claims of implemented functions):

```matlab
model = alev4.createStructuredNoiseModel(geometry, overrides);
active = alev4.selectStructuredNoiseRoi(model, geometry);
result = alev4.simulateStructuredExposure(irradiance, readout, ...
    exposure_s, frame_seed, model, geometry);
result = alev4.simulateStructuredSpatialExposure(input, input_grid, ...
    geometry, readout, exposure_s, frame_seed, model, spatial_options);
```

An absent/disabled model must delegate directly to the corresponding existing
entrypoint and return its exact struct. Do not append extra metadata, normalize
legacy outputs, draw RNG values, or reassemble readout fields in this branch.
Validate an explicitly supplied model deterministically before dispatch so
disabled status does not hide malformed fields. Compare `isequal` on entire
results and caller RNG states, including failure paths.

For enabled operation, return a new, clearly identified result schema carrying
the old validated readout *configuration*, the noise model, stage order,
component arrays and observations. The enabled zero-component case can preserve
the exact legacy *readout* through a documented no-effect branch inside the
new envelope. Exact whole-result identity with legacy and a new envelope are
different promises and must be stated separately.

## Map and coordinate contract

The model owns full-grid deterministic maps, independently of the active ROI:
achromatic PRNU multipliers, nonnegative dark rates in electrons/pixel/second,
and signed electronic offset maps in electrons. Store full-grid size, pitch,
origin and CFA association; validate geometry compatibility before cropping.
Selection is only `rows = r:(r+h-1)`, `cols = c:(c+w-1)` using Phase 3 one-based
coordinates. All four ROI parities must retain each photosite's map value.
Changing the ROI must not regenerate or renormalize a map. The legacy random
stream does not promise noisy crop/full-frame equality; do not imply otherwise.

Start with explicit maps. If generated maps are added, use a separate
realization seed and stable generation contract, and materialize them once.
Reject nonfinite/negative PRNU, nonfinite/negative dark rate, shape mismatch,
unknown fields and unsupported ranges. Do not silently normalize a supplied
PRNU map to mean one. Record the nominal interpretation and actual mean.

## Component placement

1. Call the existing `integrateExposure` once for baseline photoelectron and
   incident-photon expectations.
2. Multiply only baseline photoelectrons by active PRNU. Compute dark mean
   from dark rate times exposure, without area, fill factor, QE or spectral
   bin width a second time.
3. Draw photo and dark Poisson components independently, with independent
   enable policies, then add them into one collected-charge plane.
4. Clip that total exactly once at the common physical full well.
5. Add declared shared and path-specific fixed electronic offsets, temporal
   row/column terms and existing per-pixel electronic noise. Retain signed
   values; do not clip them to zero or full well.
6. Apply each path's existing gain, black offset, rounding and ADC clipping.
   Black offset is applied once. Call existing `mergeDualGain` using only
   observed high/low RAW plus configuration. Do not subtract simulated truth
   maps from the merge as if they were measured calibration.

Keep baseline expected photoelectrons, PRNU-adjusted photoelectrons, dark
expectation, component draws, collected total and stored total distinct.
`reconstruction_valid` remains the observable merge validity intersected with
the independently known physical saturation mask; it does not certify an
unbiased estimate in the presence of electronic fixed offsets.

## RNG contract and hazards

The old single path draws Gaussian noise only for positive configured RMS.
The old dual path always draws high then low Gaussian arrays after its
Poisson sampler. Poisson sampling consumes a mean-dependent number of uniforms.
Moving or adding a draw changes seeded legacy results. Consequently, keep the
disabled legacy dispatch intact and give enabled new components stable named
streams rather than extending that old sequential stream.

Use a caller-RNG `onCleanup` guard around every public stochastic operation.
For each component, deterministically initialize an independent named stream
from recorded frame/sequence identity and its stable component tag. Validate
seed ranges before converting numeric representations. MATLAB integer
arithmetic saturates rather than providing convenient unsigned modular
overflow: specify arithmetic explicitly, keep intermediates representable,
and avoid ad hoc overflowing hash multiplication. State the same-runtime
guarantee; distinct seeds are not evidence of cross-runtime stream identity.

Changing dark-shot policy must leave the photo draw unchanged; enabling a
shared row term must leave column and path-specific innovations unchanged;
changing high-path RMS must leave the low-path innovation unchanged. Tests
must compare retained standardized innovations or component arrays, not only
the final quantized image. For an initial independent-frame model, explicit
frame identities and white temporal covariance are sufficient; do not claim
AR, flicker or `1/f` behavior unless implemented and independently tested.

## Numerical hazards

Check PRNU multiplication, rate/exposure multiplication, charge summation,
offset/noise addition and gain conversion for finite results. Reject positive
underflow that erases requested charge where the contract requires it; preserve
exact zero endpoints. `samplePoisson` supports each mean only through `1e9`;
deterministic charge and separately sampled components need an explicit total
range policy. Dense full-grid maps can be much larger than a small active crop;
bound aggregate retained samples as well as individual dimensions. Statistical
tests should avoid ADC/physical clipping except where censored behavior is the
target, and should predeclare tolerances.

## Existing artifacts cannot carry new semantics

`exportDualGainBundle` validates expected electrons against incident photons,
requires deterministic collected charge to equal expectation when the old
photo shot flag is disabled, and requires readout to equal stored charge when
old per-pixel read RMS is zero. Dark charge and fixed offsets invalidate those
old assumptions. `spatialValidateResult` also checks a fixed operation order
and exact legacy replay. Do not loosen those checks or serialize structured
results under their old identifiers. Add a new versioned Phase 4 contract and
independent verifier; preserved readers should continue rejecting new semantics.

## Recommended acceptance cases

Whole-result disabled identity for single, dual and spatial APIs; zero-effect
readout identity; immutable caller configuration; full/crop identity at all
four parities; caller RNG restoration on success and on late overflow; component
isolation toggles; scalar analytical PRNU/dark/offset examples; dark variance
versus exposure; one shared total shot charge in both paths; row/column and
cross-path covariance plus wrong-model controls; signed offsets at both ADC
rails; and a new-artifact corruption case whose hashes have been recomputed.
