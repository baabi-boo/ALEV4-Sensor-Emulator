# Wave 03 agent B: complete native structured bundle I/O

## Implemented contract

Owned files: `exportStructuredBundle.m`, `readStructuredBundle.m`,
`structuredBundleUtil.m`, `docs/PHASE4_ARTIFACTS.md`, and this report.

`exportStructuredBundle(result,directory)` accepts enabled exposure/spatial
results; the reader's first output preserves the complete original result.
Both call agent A's strict `structuredValidateResult`, with no random replay.
The entire spatial baseline, including legacy signed analog/history fields,
PSF, reports and readouts, is retained. Sequence envelopes remain unsupported;
individual enabled frames are exported and linked by the demo summary.

The frozen `typed-tree-v1` format has exactly `structured.json` and `data.bin`.
It preserves original struct field order, scalar/map form, native shapes and
double/uint16/logical classes. Payload leaves use contiguous depth-first
offsets, little-endian encoding, true C row-major order, exact role units and
one whole-payload SHA-256. Strict JSON kinds/fields, 2 MB JSON, 100 million
numerical samples, depth/node limits and empty-array bounds are enforced.

Reader checks include unknown fields, traversal/alias paths, extras/missing
files, symlinks, hardlinks, hashes, byte totals, class, shape, offsets, units,
logical byte values, finite values and semantic inconsistencies after rehash.
Writer preflight refuses existing destinations, writes an owned sibling stage
and manifest last, verifies exact native readback, then renames for publication.
Cleanup checks identities and deletes only its recorded owned files; unknown
or substituted entries remain intact. Caller RNG is preserved on both paths.

## Limits

No full preserved acceptance, fresh-process release repeat, new CI, native
MATLAB/JVM branch, or injected mid-write publication failure was executed by
this task. Concurrent adversarial filesystem replacement is unsupported.
Unicode character extents retain runtime-native code units; incompatible
native Unicode representations reject. Scientific numerical bytes are portable.
Stochastic support and deterministic consistency do not prove PRNG origin.
This is development I/O evidence, not Phase 4 release or calibration acceptance.
