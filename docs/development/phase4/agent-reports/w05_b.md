- Full-domain proof: equal scheduled seeds imply `64(i-j)+(t-u)=0 mod 2^32`. Distinct tags have distinct residues modulo 64, hence `t=u`; then `i-j=0 mod 2^26`. With `1<=i,j<=2^26`, this forces `i=j`. Adding the sequence seed does not affect injectivity; intermediate additions stay below `2^33`.
- `simulateNoiseSequence.m:168–205` canonicalizes seed/index arithmetic; strictly increasing absolute indices permit gaps, prohibit repeats/reversal, and reject consecutive overflow. Calls use only arguments and absolute indices; no persistent/global sequence state exists. The period would repeat beyond the advertised domain.

Zero or inactive components do not advance another component. `simulateNoiseSequence.m:85–89,209–223` retains EI only as envelope metadata.
