## Implementation

`createStructuredNoise(full_grid_size, overrides)` requires an explicit grid
and accepts optional partial overrides, including partial named electronic
components. It validates a canonical model passed as its second argument. The
stored grid must exactly match the explicit argument even when disabled. Grid
bounds match the geometry contract: positive integer dimensions and at most
100 million pixels. It rejects unknown top-level/nested fields, malformed
structures, unsupported shapes, nonfinite/complex maps, negative PRNU or dark
rates, negative or nonscalar RMS values, invalid logical switches, unsupported
schema versions, and malformed/duplicate source identifiers.

Maps are explicit scalar uniforms or matrices matching the entire full grid.
Numeric settings become dense doubles. PRNU is never normalized; zero PRNU and
signed electronic fixed offsets are retained. Scalar maps remain compact in
the model. No fixed-map seed or generator exists. Defaults not numerically
specified in the design are `dark_shot_noise=true`, reference temperature
293.15 K, and realization label `ASSUMED-P4-DEFAULT`. These remain synthetic
assumptions. The source list refers to the eight relevant `ASSUMED-P4-*`
records in the Phase 4 source register.

`structuredNoiseMaps(model, geometry)` uses `createSensorGeometry` and the new
constructor for validation, then selects one-based full-grid ROI coordinates.
Its six output fields are `prnu`, `dark_current_e_per_s`, `shared`, `single`,
`high_gain`, and `low_gain`. Fixed maps become active dense-double matrices;
each electronic component retains its three scalar RMS settings. It consumes
no randomness and leaves caller inputs unchanged.

Schema coordination was sent to the exposure implementation and wrapper
agents. Their constructor/extractor call pattern is compatible with this
implementation.
