## Configuration suite

`test_phase4_config` returns the required report fields `suite`, `status`,
`passed`, `test_count`, `tests`, and `metrics`. Its nine frozen group names are:

1. `defaults_partial_revalidation`
2. `strict_schema_fields_and_structure`
3. `strict_grid_and_full_grid_match`
4. `nonnegative_maps_and_signed_offsets`
5. `rms_and_temperature_ranges`
6. `realization_and_source_identifiers`
7. `numeric_representation_canonicalization`
8. `all_bayer_roi_parity_map_identity`
9. `constructor_map_rng_and_caller_isolation`

The suite rejects malformed scalar structures, top-level and component fields,
schema versions, logical switches, grids, map shapes, map values, RMS values,
temperatures, realization labels, and source-ID lists. It covers disabled-model
validation, explicit full-grid mismatch despite matching active crop dimensions,
one-row/one-column grids, bounded descriptor-only maximum grids, scalar uniform
maps, signed fixed offsets, exact zero responses, and unnormalized PRNU.

Accepted numeric representations include ten MATLAB numeric classes and sparse
arrays, with exact dense-double canonicalization and preserved logical switches.
The crop fixture uses an asymmetric 5-by-7 full grid and checks all four Bayer
patterns at all four ROI-origin parities, including explicit expected CFA
patterns. It also checks the final photosite, scalar expansion, every named fixed
offset, untouched RMS values, and caller-value/RNG isolation on success and error.
No random draws are expected from these APIs.

## Deterministic core suite

`test_phase4_core` uses the same report shape and has eleven frozen groups:

1. `independent_scalar_stage_oracle`
2. `single_gain_transfer_and_signed_quantization`
3. `dark_only_saturation_and_shared_well`
4. `zero_exposure_fill_and_prnu`
5. `fixed_offsets_after_well_and_gain_black_once`
6. `fixed_map_crop_exposure_identity`
7. `disabled_whole_result_identity`
8. `distinct_adc_physical_and_reconstruction_masks`
9. `raw_only_merge_transition_oracle`
10. `arithmetic_failures_and_rng_restoration`
11. `deterministic_wrong_model_controls`

The principal independent oracle uses a 2-by-3, one-bin RGGB fixture with
explicit area, fill, width, QE, exposure, PRNU, dark rates and shared/path offsets.
Its intermediate expected arrays are hand-calculated exact binary fractions.
No production integration, map, noise or merge helper generates the expected
photocharge, dark charge, total charge, well-limited charge, signed electronics
or reference RAW. A small independent scalar ADC check uses signed `floor` of
absolute analog DN; it does not call production `round` and tests negative
half-DN ties explicitly. Comparison tolerance is exactly zero.

The suite checks dark-only physical saturation; combined photo/dark saturation
at one well; zero exposure, fill and PRNU; dark charge independent of PRNU;
uniform nonunit PRNU without normalization; signed offsets after well clipping;
electronic gain and black offset applied once; fixed maps unchanged with frame
seeds; and observed-channel merges at both transition endpoints and the midpoint.
An altered hidden expectation compensated by a fixed offset leaves recorded RAW
and the merged result identical, preventing use of inaccessible truth in merge.

There are 32 deterministic full/crop exposure comparisons across four Bayer
patterns, four ROI parities and both readout modes. Eight disabled-wrapper
comparisons check entire legacy results in single and dual gain, exposure zero
and nonzero, and both seed endpoints. Separate exact fixtures distinguish actual
ADC overflow/underflow, unclipped codes rounded to either rail, conservative
rail usability, physical saturation and reconstruction validity.

The 37 rejected input/numerical cases include seed/exposure/irradiance errors,
shape and geometry conflicts, disabled-grid mismatch, PRNU/dark multiplication
overflow and underflow, erased positive products, total-charge overflow, unsafe
fixed/RMS values, gain underflow/overflow, separate photo/dark Poisson limits,
late overflow after actual shot/Gaussian draws, signed-cancellation subnormals,
and the coordinating agent's retained-allocation guard. The resource fixture
uses `[1 1538462]` pixels at one spectral bin: 65 samples per pixel already exceed
100 million, so a scalar input must reject with `ALEV4:StructuredNoiseSize`
before expansion or integration. Every error check verifies caller RNG state.

Eleven deterministic wrong models fail the same exact-comparison predicate:
renormalized PRNU, PRNU applied twice, dark modulated by PRNU, dark rate used as
an exposure-independent offset, separate photo/dark wells, offsets before the
well, signed electrons clipped back to the well, doubled black level, omitted
shared offset, high-path use of low gain, and negative half-ties rounded toward
zero. These controls test fixture sensitivity; they are not alternative
production implementations.

## Defect reported and integration fix

The adversarial identifier fixture `['x' char(233)]` initially caused Octave's
`regexp` to throw an unclassified invalid-UTF-8 error before the constructor's
`ALEV4:InvalidStructuredNoise` rejection. The coordinating agent fixed
`createStructuredNoise` by rejecting character codes outside printable ASCII
before calling the regular expression. Both realization IDs and source-list
entries now pass the retained strict-error regression. This agent did not edit
that production helper.

Two early test failures were fixture/harness issues, not production defects:
MATLAB/Octave reject excess arguments before a fixed-signature function body,
so those checks accept the relevant native arity identifiers; and cell-valued
malformed settings must be assigned into a struct field rather than unwrapped
by the struct constructor. Both were corrected without weakening malformed
setting checks.
