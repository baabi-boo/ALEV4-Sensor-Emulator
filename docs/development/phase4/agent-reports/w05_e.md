## Findings

- No new defect identified within the documented supported contract.
- Exporter ownership is explicit rather than a nested `onCleanup` closure:
  failure closes the active handle before identity-checked removal and
  rethrows the original exception even when cleanup warnings become errors.
- `openOwned` checks stage identity and absence before opening; failed opens
  do not return a live handle. Failure to observe the newly opened file's
  identity closes that handle without authorizing deletion of an unknown file.
- Payload/manifest short writes, write exceptions, `ferror` and close status
  all prevent publication. Counts and payload bytes are checked; the manifest
  is written last and full native readback precedes the directory rename.
- Publication checks destination absence again, detects nested moves, and
  verifies the directory identity. Cleanup removes recorded files only and
  never recursively removes foreign, replaced or relocated content.
- Reader guards close payload/manifest/hash handles on failure. It checks
  exact inventory, ordinary single-link distinct files, actual length/hash,
  then repeats directory/file observations after semantic validation.
- Numeric leaves preserve double/uint16/logical class and exact native size;
  reversed-dimension write/read transformations implement C row-major order.
  The asymmetric 2-by-3-by-4 test uses explicit scalar/byte loops as its oracle.
- Strict JSON kinds, exact node fields, contiguous offsets, class widths,
  finite values, canonical logical bytes and path-derived units are enforced.
  Final totals prohibit padding/unreferenced bytes. Shape positive-dimension
  products remain bounded even for empty arrays; node/depth/cell limits apply.
- Canonical result validation checks configuration, maps, stages, retained
  charge/electronics, ADC and observed-channel merge, including full spatial
  history. Rehashing inconsistent physics cannot bypass those checks.
- A coherent alternative stochastic realization is deliberately accepted;
  seed schedules/runtime labels are associations, not PRNG authentication.

  `git branch --show-current`, `git log -1` and `git submodule status`.
  Inspected all 20 declared native artifact groups and fault-injection source;
  no numerical suite or new runtime probe was executed by this task.
- The coordinator's 282-case development pass was not rerun or promoted to
  release evidence. Complete clean-source acceptance and CI remain pending.
- Ordinary existing ancestors, stable identity facilities and nonconcurrent
