# Wave 1 / agent F — quantitative Phase 4 acceptance design

## Scope and execution status

Reviewed `AGENTS.md`, `PHASE4_PLAN.md`, and the Phase 2 noise/numerical-edge
and Phase 3 integration test conventions. This report proposes tests; it does
not claim a Phase 4 implementation or executed acceptance. Production files
were not changed. The proposed scope uses supplied fixed maps and independent
frames, with EI as a recorded label and no implicit exposure/gain policy.

## Deterministic oracle first

Use small asymmetric nonsquare arrays and a scalar oracle that does not call
the new production helpers. With photo and dark shot noise disabled, compute:

1. `photo = baseline_photo .* prnu`.
2. `dark = dark_rate_e_per_s .* exposure_s`.
3. `collected = photo + dark`; `stored = min(collected, full_well_e)`.
4. `read_p = stored + fixed_shared + fixed_p` when all temporal RMS values are zero.
5. `analog_dn_p = read_p * gain_p + black_level_p`.
6. Round ties away from zero, then clamp to `[0, 2^bits-1]`.

Use exact representable fractions wherever possible. Otherwise use a stated
ULP tolerance for independently ordered arithmetic, not a broad percentage.
Check all retained stages, not only final DN. In particular, total expected
electrons can exceed incident photoelectrons because dark charge is added.

Recommended independent deterministic groups:

- Supplied PRNU values `[0, .5, 1; 1.25, 1.5, 2]` remain unchanged; no hidden
  map normalization. A zero-PRNU site can still accumulate dark charge.
- Heterogeneous dark rates and two exposures prove electron/second scaling;
  exposure zero removes both photo and dark charge but preserves electronic
  offsets/noise. Zero photo collection/fill factor does not erase dark charge.
- Positive and negative fixed offsets prove addition after physical clipping;
  electronic readouts may lie below zero or above full well.
- Gain changes scale electron offsets once; black level is added once in DN.
- Dark-only charge can cause physical saturation. Photo and dark charge must
  share one well, rather than being clipped separately before addition.
- Full-grid maps crop by full-grid coordinates for all four ROI-origin
  parities and all four CFA patterns. Compare deterministic crops exactly;
  do not require separately generated random crops to equal full-frame draws.
- Disabled wrappers return the whole legacy result exactly for single,
  dual, and spatial paths, including seed endpoints and caller RNG state.
- Inputs/configuration are unchanged after successful calls and early/late
  failures. Unknown fields, negative rates/RMS, nonfinite values, malformed
  maps, unsupported products/sums, and Poisson range overflow reject.

## Statistical formulas and preregistered tolerances

Keep statistical fixtures away from every well/ADC rail and assert that no
clipping occurred. Do not discard censored observations and then apply
uncensored formulas. Subtract each site's known deterministic mean when maps
vary; pooling heterogeneous means would falsely inflate variance.

Let `lambda` be the sum of the means of the Poisson components that are
enabled. Turning photo shot noise off changes its variance contribution but
must not change the independent dark-shot policy. Let independent Gaussian
electronics have total variance `g`. For an unclipped pixel:

| Quantity | Exact target |
| --- | --- |
| Mean | `mu_photo + mu_dark + fixed_offsets` |
| Variance `v` | `lambda + g` |
| Fourth central moment `m4` | `lambda + 3*v^2` |
| Mean standard error | `sqrt(v/N)` |
| Unbiased sample-variance standard error | `sqrt((m4 - (N-3)/(N-1)*v^2)/N)` |

For paths sharing shot charge and shared Gaussian electronics, write their
centered signals as `X=A+H`, `Y=A+L`. Let `a=Var(A)`, and let `h,l` be
independent path-specific variances. Then:

- `Cov(X,Y)=a`.
- `Var(X-Y)=h+l`: shared charge and shared electronics cancel exactly.
- For the known-mean covariance estimate `mean(X.*Y)`,
  `Var(X*Y)=lambda + 2*a^2 + a*(h+l) + h*l`.
- For an independent photo/dark pair, the covariance target is zero and the
  product variance is `mu_photo*mu_dark` when both shot processes are enabled.

The existing Phase 2 suite uses seven analytical standard errors. A Phase 4
suite may retain a comparable diagnostic, but must not describe seven/eight
SE as an exact Gaussian tail guarantee for Poisson/product statistics.
One rigorous, inexpensive acceptance allocation is:

- Allocate total false-failure budget `alpha=0.01` under the declared ideal
  independent-draw model: `0.005` for non-Gaussian comparisons and `0.005` for
  Gaussian comparisons.
- Limit the first family to 32 scalar stochastic comparisons. Use
  `z=sqrt(32/0.005)=80` times the exact SE above. Chebyshev plus the union bound
  then gives at most `0.005` family failure probability without a normal-tail
  approximation. Use `N=262144` pixel draws for these tests; this gives about
  22% variance tolerance for a moderately sized Poisson mean. Exact
  deterministic tests and wrong-model controls supply finer structural checks.
- Count the actual comparisons and fail test setup if the allocation is
  exceeded. These are deliberately conservative mathematical bounds, not
  confidence limits on a measured camera. Fixed-seed PRNG execution is a
  reproducibility mechanism, not proof of probabilistic independence.

For purely Gaussian components use much tighter finite-sample concentration
bounds. For `N` independent zero-mean Gaussian values of variance `v`, set
`t=log(4*K/alpha_family)` for the preregistered Gaussian comparison count `K`:

- `abs(mean(x)) <= sqrt(2*v*t/N)`.
- The known-mean second moment lies between
  `v*(1-2*sqrt(t/N))` and `v*(1+2*sqrt(t/N)+2*t/N)`.
- A Gaussian known-mean covariance can be bounded by polarization of
  `U=X/sigma_x+Y/sigma_y` and `V=X/sigma_x-Y/sigma_y` and the same second-moment
  bounds. For independent standardized variables, a conservative absolute
  covariance tolerance is `sigma_x*sigma_y*(2*sqrt(t/N)+2*t/N)`; the two
  second-moment bounds together have failure probability at most `4*exp(-t)`.

Zero-variance conditions are exact identities; do not divide by zero or turn
them into statistical checks. Record the chosen family budgets, sample counts,
targets, measured statistics, and computed tolerances in suite metrics.

## Do not inflate the independent sample count

Pixels in the same row share row noise, and pixels in the same frame share
frame noise. Counting all `H*W` pixels as independent would make tolerances
incorrectly tight.

- Test row-only noise on an `8192 x 2` image: each row supplies one independent
  draw. Assert exact equality within each row; test variance across rows.
  Pair disjoint rows to test zero between-row covariance.
- Transpose that fixture for column-only noise.
- Test shared versus path-specific row noise with the same row grouping.
  Shared row draws must agree across paths; path-specific residual products
  must have zero expectation.
- Test mixed components by retaining the component arrays and validating each
  separately, then check their exact sum. Use independent frames for a mixed
  covariance measurement, rather than pretending every pixel is IID.
- For frame-wide noise, the independent sample count is the number of frames.
  Use roughly 1024 tiny frames (or the public sequence helper) rather than
  large repeated images. Release each frame after accumulating statistics.
- For lag-one and lag-two temporal covariance, select disjoint frame pairs
  separately for each lag. Overlapping lag products are not IID observations.
  Test fixed-map cancellation and `Var(frame2-frame1)=2*v` using disjoint
  equal-exposure pairs; account for two independent Poisson contributions in
  the fourth moment when charge is stochastic.

At distinct pixels, with independent photo/pixel read noise, electronic
covariance is `row_variance*[same row] + column_variance*[same column] +
frame_variance`. Across gain paths only the declared shared components enter
this expression; at the same pixel also add shared shot variance. Subtract
fixed maps before evaluating any such covariance.

## Required wrong-model controls

Run each control through the same acceptance predicate and assert rejection:

| Mistake | Control that must fail |
| --- | --- |
| Independent shot charge in the two paths | Permute the low-path observations or use an independently drawn charge; shared covariance and difference-noise checks reject. |
| Reused path-specific Gaussian stream | Replace a low residual by a scaled high residual; zero cross-covariance check rejects. |
| Row/column axes exchanged | Asymmetric nonsquare fixture and within-row/within-column exact equality checks reject. |
| Pixel noise masquerading as row noise | Independent values within each row violate exact within-row equality. |
| Fixed map redrawn every frame | Compare retained maps and fixed-only frames across distinct frame seeds. |
| Noise inserted before the well | A saturated fixture with signed offsets must retain readouts above the well; a second clipping step rejects. |
| Black offset counted twice | Scalar DN oracle rejects at unsaturated representable fractional electrons. |
| PRNU applied twice or applied to dark current | Zero-PRNU/nonzero-dark and nonunit-PRNU analytic examples reject. |
| Dark current treated as exposure-independent offset | Two distinct exposure times and zero exposure reject. |
| Metadata-only EI changes physics | Same input/exposure/configuration/seeds, different EI labels: all physical arrays must match exactly. |

Controls should be compared with frozen bounds, never used to tune a bound
until one preferred seed passes. Keep statistical controls well separated from
the correct target so they do not become a second flaky hypothesis test.

## Clipping, quantization, and sequence acceptance

Use deterministic one-row sweeps around all relevant thresholds: high-path
upper rail, both merge endpoints, low-path upper rail, and physical full well.
Include signed offsets and exact half-DN ties. MATLAB/Octave `round` uses
ties away from zero, so `floor(x+.5)` is not a valid negative-DN clipping-flag
oracle. A scalar reference can use `sign(x)*floor(abs(x)+.5)`.

Check quantized dark frames against actual Gaussian rounding-bin probabilities
computed with `erfc`, or retain the established Phase 2 quantizer oracle;
do not assume independent uniform quantization error of `step^2/12` in the
shadow regime. ADC clipping flags, conservative rail usability, physical
saturation, and reconstruction validity remain separate checks.

For independent sequences, require full-run versus prefix/suffix continuation
identity when addressed by the same explicit frame indices/seeds, repeatable
reset, distinct frame noise, unchanged maps, and unchanged caller RNG. The
same sequence in a separate process must yield byte-identical artifacts in
the same runtime/version. No cross-runtime stream identity is promised.

## Test integration and cost

Follow current suite reports: explicit named groups, `status`, `passed`,
`test_count`, and retained numerical metrics. Do not mark a missing suite as
passed. Separate deterministic/configuration, stochastic-components,
sequence/sweeps, spatial integration, and artifact tests so failures are
locatable. Run full preserved acceptance only at meaningful integration gates.

Largest suggested statistical fixture is 262144 pixels with one spectral bin;
run fixtures serially and discard arrays between groups. Tiny sweep/map demos
are sufficient for retained artifacts. A full 4608-by-3164 noisy frame is not
needed to validate any of these mathematical contracts.
