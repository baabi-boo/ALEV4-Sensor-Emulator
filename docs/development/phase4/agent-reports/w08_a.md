  `docs/PHASE4_USAGE.md:147–150` names expected, collected, stored and signed
  charge plus validity concepts, but does not identify their exact fields.
  In particular, `readout.expected_electrons` now means expected **photo plus
  dark** charge, whereas the legacy expectation excludes dark current.
  `matlab/+alev4/simulateStructuredExposure.m:120–150` defines the distinction.
  Add a short field table there for `baseline_expected_electrons`,
  `readout.expected_photoelectrons`, `readout.expected_dark_electrons`,
  `readout.expected_electrons`, `readout.collected_electrons`, and
  `readout.charge_electrons`, with the single/dual signed-readout paths.
  Include `reconstruction_valid = adc_usable & ~full_well_saturated` for
  single gain and `merged.valid & ~full_well_saturated` for dual gain.
  This is a usability clarification, not a detected implementation mismatch.
