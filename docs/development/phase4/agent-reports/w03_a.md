## Contract implemented

`result = alev4.structuredValidateResult(result)` accepts only complete enabled
`exposure` and `spatial_exposure` results, returning valid input unchanged.
Unknown/missing fields, noncanonical configurations/geometry/model, incorrect
classes, sparse scientific arrays, wrong shapes, nonfinite values, and altered
assumed/synthetic labels, units, order, temperature or stream metadata reject.
All 18 seed fields are checked against the documented modular tag schedule.
Runtime must identify MATLAB or GNU Octave and an explicit printable version;
it need not equal the validating host because streams are never replayed.

Independent per-band accumulation and Bayer indexing establish baseline and
incident expectations. Full-grid maps are independently cropped by the ROI.
PRNU, exposure-scaled dark charge, total expectations, collected charge, one
shared well, fixed/row/column/frame/pixel sums, signed readouts, gain/black,
rounded RAW and each logical clipping/validity mask are reconstructed.
Dual merging is recomputed from observed RAW/configuration only. Complete
native types/shapes are checked before tolerance-based reference comparisons.
Direct deterministic associations and zero-RMS draws are exact. Shot-disabled
charge equals its expectation exactly; shot-enabled charge must be nonnegative
integer-valued, with zero-mean sites exactly zero and supported Poisson means.
Only active electronic paths may contain draws; shared pixel noise is zero.
Overflow, erased product support and unsupported normal-range arithmetic reject.

Spatial validation requires the intact legacy baseline including both reports.
`spatialValidateResult(baseline,false)` checks optics/sampling association;
complete retained legacy charge/readout/RAW/merge semantics are also checked.
Configuration, geometry, sampled input, seed, exposure, expectations, role and
combined operation order must agree. Optical/sampling reports are recomputed
deterministically. Portable scalar spatial provenance remains informational.
The function never invokes a stochastic simulator or draws a random component.
