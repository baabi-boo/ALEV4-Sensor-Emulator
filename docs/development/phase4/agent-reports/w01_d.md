# Wave 1 — agent D: local numerical runtime

## Task and outcome

Provisioned an isolated, user-owned numerical runtime outside the repository at
`/workspace/scratch/c29e5f205eec/runtime`. No production code, system packages,
security settings, dependency pins, or Git history were changed.

The environment initially had no Octave, MATLAB, sudo, conda, or micromamba.
A user-owned `APT_CONFIG` selected the environment's existing Debian snapshot
repository and isolated package lists/cache/status. The standard APT client
validated its signed package indexes and downloaded the package dependency
closure; `dpkg-deb -x` extracted that closure into a user-owned prefix.
The inherited network proxy, CA trust, and signature verification were retained.

## Validated tools

- GNU Octave 9.4.0 (`octave` package 9.4.0-1).
- Octave image 2.16.0 (`octave-image` 2.16.0-2).
- Octave statistics 1.7.3 (`octave-statistics` 1.7.3-2), registered but not needed
  by the project's custom Poisson sampler.
- Wrapper: `/workspace/scratch/c29e5f205eec/runtime/bin/octave`.
- Use by prepending that `bin` directory to `PATH` for test commands.

The wrapper sets the relocated Octave data/executable prefixes and library
search directories, then executes `octave-cli`. Package registration was rebuilt
under the relocated runtime. A compiled image-operation smoke test
(`imdilate([0 1 0], ones(1,3))`) and a 2-by-2 zero-exposure project sensor simulation
both passed. Native MATLAB was not installed or executed.

## Reproducibility and storage

The package closure contains 251 archives, downloaded as 149 MB. Exact package
metadata, archive sizes, and SHA-256 hashes are recorded in the task runtime's
`packages.json`; the download log and isolated APT configuration are retained.
The extracted runtime occupies approximately 581 MB. Downloaded archives and
package indexes were removed after successful validation to avoid duplicate
storage. This task did not run or claim a phase acceptance pass; the parent
agent owns baseline and complete acceptance execution.
